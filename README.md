# 🧠 Science & Nature Quiz App — Pasang Tamang

A multiple-choice science quiz app that fetches real questions from the Open Trivia DB API.

## 🔗 Live Demo
[pasanghilp-art.github.io/quiz-app](https://pasanghilp-art.github.io/quiz-app)

## 📸 Features
- 15 Science & Nature questions per round
- Mixed difficulty levels (Easy, Medium, Hard)
- 20 second timer per question
- Score tracker with points based on difficulty
- Correct/wrong answer feedback with explanation
- Progress bar showing quiz completion
- Results screen with correct, wrong, and skipped counts
- Fallback offline questions if API fails
- Fully responsive on all screen sizes

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript (Vanilla)
- Open Trivia DB API (free questions)
- Fetch API (API calls)
- Google Fonts (Nunito)
- GitHub Pages (deployment)
